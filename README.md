# mgpsearch

En statisk sökapplikation i javascript som låter DIG gräva i vad det talats om i gamla MGP-avsnitt.

Innan DU tar ord till dig bör du veta att detta projekt är blessed av the Prizzle.

## Disclaimer

AI har använts i skapandet av detta projekt. Vad trodde du? 

## Avsnitt saknas

Nya avsnitt läggs till i takt med att jag känner för det.

## Autokorrigeringar

`scripts/corrections.json` läses av python-script för autokorrigeringar.
